# 冻结方法参数

本文件把交付包实际使用的冻结参数列成可核对形式。运行时请以 `config/example_config.json` 和包内复制的冻结源代码为准，不要根据输出结果临时调参。

## 数据和标定

| 参数 | 冻结值 |
|---|---:|
| 输出帧数 | 500 |
| 输出深度像素 | 351 |
| 输出横向像素 | 500 |
| 轴向标定 | 6.7 um/px |
| 横向标定 | 12.7 um/px |
| MATLAB 轴顺序 | z, x, frame |
| Python 轴顺序 | frame, z, x |

## MATLAB 导出

| 参数 | 冻结值 |
|---|---:|
| `Thr` | 85 dB |
| `IMcropRg` | 50:400，351 行 |
| `Nsub` | 10 |
| 相位补偿 | 开启 |
| 中位相位位移 | 开启 |
| 亚像素配准 | 开启 |
| `NumEV` | 2 |
| `p_tis` | 不保存 |
| 注册位移 | 保存 |
| `p_bld_ed` | MAT-v7.3，single |

## 跟踪和定位

| 参数 | 冻结值 |
|---|---:|
| alpha 敏感性 | 0.10、0.15、0.20 |
| 主 alpha | 0.15 |
| X 方法 | X4：局部稳健质心 + 孤立跳变修正 |
| X 搜索范围 | 既有 Viterbi 轨迹附近的局部窗口 |
| 全图 argmax | 不使用 |
| z | 当前 alpha=0.15 tracking 的 `z_upper_px` |
| 慢轴分段 | front 0–166；middle 167–332；rear 333–499 |

## 拖尾指标

| 参数 | 冻结值 |
|---|---:|
| 中央 ROI | 血管横向宽度的 40% |
| z 操作性下边界 | `z_upper + round(D / 6.7)` |
| 主 guard | 2 px |
| guard 敏感性 | 0、2、4 px |
| 主原始 AUC 窗口 | 0–200 um |
| 分段窗口 | 0–100、100–200、200–300 um |
| 主帧集合 | `assessable` 且主 AUC 有效 |
| 敏感性帧集合 | `assessable + uncertain` 且主 AUC 有效 |
| `not_assessable` | 排除 |
| 无效帧处理 | 不补零、不插值 |
| 扫描级聚合 | 所有有效可评估帧 pooled median |

## 边界

这些参数来自当前项目的冻结流程。交付包装器只负责路径、顺序和输出整理，不改变核心函数的计算公式。单卷运行不会生成完整批次的 Gate A；完整批次门控必须在原项目规定的冻结批次上单独执行。
