# D235–D285 共同直径区间结果解释

日期：2026-09-12

本文件记录当前项目对 D235 与 D285 共同直径区间的结果解释。这里优先讨论 SV 研究本身，并将师兄历史结果仅作为同直径区间的方向性参照。该文件不修改任何既有数值、分析合同或冻结结果。

## 一、核心判断

在共同存在的 D235 与 D285 两个直径条件下，我们当前 SV 结果与师兄历史结果在三个关键方向上是一致的：

1. **absolute tail：D235 > D285**；
2. **vessel-core / denominator：D235 < D285**；
3. **normalized tail：D235 > D285**。

因此，从 235 μm 增大到 285 μm 时，血管核心信号升高，而血管下方 absolute tail 降低，归一化 tail 进一步降低。

## 二、当前 SV 结果

### 1. 正式 fixed-diameter v2

在正式 SV v2 中，五个匹配流速下：

- `tail100`：D235 > D285；
- `tail500`：D235 > D285；
- `RI100`：D235 > D285；
- `RI500`：D235 > D285。

这说明 235→285 μm 的 tail 下降并不依赖单一窗口或单一归一化指标。

### 2. 师兄指标迁移后的 SV Stage B

Stage B 使用师兄完整的定位、assessability 与指标定义。D235→D285 的方向仍保持：

- `raw_AUC_200`：下降；
- `vessel_core_P95`：上升；
- `normalized_AUC_um`：下降。

五个流速全部保持这些方向。

因此，235→285 μm 这一段的方向对当前正式指标、师兄式 AUC/P95 指标以及定位/筛选迁移均较稳健。

## 三、与师兄历史结果的关系

师兄历史图中 D235→D285 同样表现为：

- absolute AUC：下降；
- vessel-core denominator：上升；
- normalized AUC：下降。

所以如果只比较双方都存在的 D235 与 D285，两边的主要方向是一致的。

当前两套结果真正明显不同的地方主要出现在最小直径端：

- 师兄历史直径：D185、D235、D285；
- 当前正式队列：D128、D235、D285。

因此，师兄历史的 D185→D235 与当前的 D128→D235 不能直接视为同一区间的重复比较。现有结果不能确定 128、185、235 μm 之间的真实 tail–diameter 关系是否单调。

## 四、235→285 μm 的科学解释

当前数据支持以下经验性描述：

- 随直径从 235 μm 增大到 285 μm，血管核心信号提高；
- 同时，血管下方 absolute tail 减弱；
- 因此 relative/normalized tail 下降得更明显。

这说明在该直径区间内，tail 不是简单按固定比例随 source 增强。换言之，不能用 `Tail = constant × Source` 来概括当前结果。

这一跨直径结果与同一 scan volume 内的 source–tail 正空间 coupling 并不矛盾：卷内 coupling 描述的是同一血管沿 slow-axis 的局部共同起伏，而 D235 vs D285 比较的是不同直径条件的总体水平。

## 五、当前证据边界

1. 每个 diameter×flow 只有一个 scan volume；不同 flow 不是同条件重复。
2. 该结果是描述性的直径区间观察，不建立直径对 tail 的因果效应。
3. 师兄历史结果来自不同最小直径和不同数据集，因此只能比较 D235→D285 的方向一致性，不能视为独立重复验证。
4. 现阶段可以把 D235→D285 的 `absolute tail↓ / vessel-core↑ / normalized tail↓` 作为较稳定的经验现象。
5. D128→D235 仍是后续理解 SV 直径响应最值得关注的区间；现有数据不支持外推到 D185。

## 六、当前建议的 SV 研究重点

在暂不展开算法比较的前提下，下一步更值得围绕 SV 本身回答：

- 为什么 D285 的 vessel-core signal 更高，而 absolute tail 更低；
- 这种差异如何随 tail depth 变化；
- D128→D235 与 D235→D285 是否表现出相同或不同的深度衰减规律；
- 能否用固定物理深度 profile 区分“source 强度变化”和“tail 传递/衰减变化”。

本文件仅记录当前结果解释，不启动新的分析。
