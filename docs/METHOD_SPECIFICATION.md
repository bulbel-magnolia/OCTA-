# SV 矩形拖尾定量方法规范

## 1. 适用范围与固定参数

本规范对应 `SV_Rectangle_v1_pilot`。研究对象为内径 128 μm 的管道，
横向标定为 12.7 μm/A-line，轴向标定为 6.7 μm/pixel。先导分析包含
1、3、5、7、10 mm/s 五个流速，每个流速选择前、中、后三个慢轴位置，
共 15 个 B-scan 帧。

数组顺序统一为 `depth(z) × A-line(x)`。Python 坐标使用 0 基像素中心：
第一个像素中心为 0，长度为 `n` 的图像物理边界为 `[-0.5, n-0.5]`。

## 2. 信号构建

重建后的复数重复帧记为 `E(z,x,r)`。正式 SV 信号定义为：

```text
I_sv(z,x) = Var_N(|E(z,x,r)|) = var(abs(E), 1, 3)
```

方差分母为重复数 `N`。`stru_amp = mean(abs(E),3)`、CV²、对数图、
归一化图和显示映射仅用于定位或 QC，不参与正式积分。Python 加载器拒绝
明显含负值的输入图，从入口防止背景校正图被误作 `sv_raw`。

## 3. 几何定位

### 3.0 固定表面引导的全局粗定位

当体模表面在全部帧中固定为 `z_surface=176` 时，血管顶缘先验为：

```text
z_prior = 176 + 200 μm × 1.12 / 6.7 μm/px = 209.43
```

程序在该先验覆盖的血管高度及小幅轴向余量内读取 OMAG。定位副本取
`log(1+OMAG)`，逐深度行以横向中位数和 scaled MAD 标准化，累积连续
轴向亮信号并沿横向平滑。全局最高且粗定位 CNR 达到阈值的列作为局部 X1
搜索锚点。该步骤不读取历史人工横向坐标，正式积分信号仍为线性
`sv_raw`。

### 3.1 横向边界 X1

横向定位使用与 SV 图共注册的 OMAG 图和导师方法提供的轨迹锚点。算法在
锚点周围建立局部窗，在预计血管高度内计算各列的 75% 分位数。远离锚点
的列定义局部背景和 MAD 尺度，阈值为背景加 `1.5 × 1.4826 × MAD`。

优先选择包含轨迹锚点的连续超阈值段；若不存在，则记录最强连续段作为
回退结果并使源区 QC 失败。正式横向中心 X1 为所选连续段左右边界的几何
中点。X4 稳健质心可作为轨迹锚点，不直接替代 X1。

### 3.2 轴向顶缘

在 X1 中央线的三列带内重新提取轴向 OMAG 剖面。轨迹顶缘限定搜索范围，
其上方远端窗建立稳健背景阈值。距离轨迹锚点最近的连续两行超阈值段起点
定义 `z_top`。未找到持续边缘时保留轨迹值作为回退显示，并使源区 QC
失败。

血管下缘保持浮点值：

```text
z_bottom = z_top_edge + D / dz
```

其中 `z_top_edge` 是顶缘行中心上方 0.5 pixel 的物理边界。计算过程不对
`D/dz` 取整。

## 4. 面积权重

所有矩形边界采用像素单元与物理区间的精确重叠比例。源区为物理椭圆：
横轴来自 X1 检出的局部横向宽度，纵轴为固定内径 128 μm。椭圆边界像素
通过 16 × 16 确定性子像素网格计算面积分数。

拖尾矩形横向范围与 X1 血管宽度一致，轴向范围为：

```text
z_bottom + g < z <= z_bottom + g + L
g = 0 μm
L = 500 μm
```

正式积分使用等价的连续边界重叠权重。500 μm 窗超出图像时，`Q_tail`
和 `R` 记为 NA，不以截短面积替代正式结果。

## 5. 背景

设 X1 连续段首末像素中心为 `iL`、`iR`。每个深度行固定跳过血管外侧
3 列，再各取 5 列：

```text
left  = iL-8 : iL-4
right = iR+4 : iR+8
```

左右条带全部有效像素共同计算逐行算术均值 `B(z)`；边缘裁剪或缺失值存在
时按实际有效像素数加权。算法不选择较暗一侧。`B_left`、`B_right`、标准差、
中位数和 scaled MAD 同步输出用于诊断。

默认要求双侧条带均可用。若一侧存在已确认的空间或结构问题，可在清单中
同时填写 `background_excluded_side` 与 `background_exclusion_reason`，程序
固定使用另一侧并记录 `left_only_explicit` 或 `right_only_explicit`。未声明的
单侧缺失使背景 QC 失败，程序不会根据积分大小自动挑选背景侧。

背景校正图为：

```text
C(z,x) = I_sv(z,x) - B(z)
```

所有负残差原样保留。

## 6. 剖面与积分

对 X1 横向范围建立逐行剖面：

```text
V(z) = weighted_mean_x(I_sv)
T(z) = V(z) - B(z)
P(z) = sum_x(C(z,x) * x_overlap(x)) * dx
```

正式源区、拖尾区和比值定义为：

```text
Q_vessel = sum_ellipse(C * ellipse_fraction) * dx * dz
Q_tail   = sum_rectangle(C * rectangle_fraction) * dx * dz
R        = Q_tail / Q_vessel
```

代码同时计算 `sum_z(P(z) * z_overlap(z)) * dz`。该值必须在浮点精度内与
二维矩形直接积分一致。`R` 仅在源区定位 QC 通过、源区与拖尾窗完整、背景
完整且 `Q_vessel > 0` 时报告。

## 7. 探索性检出长度

检出长度使用与拖尾起点对齐的 `T(z)` 和匹配空白噪声剖面。每 5 行组成
一个不重叠完整分箱。每个深度箱的阈值为：

```text
threshold = median(blank) + 3 * 1.4826 * MAD(blank)
```

每箱至少需要 3 个空白样本。连续两个及以上超阈值箱构成有效检出段，最远
有效箱的下边界定义可检出长度。有效段到达分析窗末端时记录为右删失。缺少
匹配空白剖面时，主积分仍执行，检出表明确记录 `not_run` 状态。

启用检测时，逐帧检测 MAT 保存实际使用的 `T(r)`、全部匹配空白样本、分箱
均值、空白中位数、scaled MAD、阈值、连续检出掩膜、参数及空白输入哈希。

## 8. 敏感性与 QC

每个正式帧同步计算五项单因素敏感性结果：X1 横向平移 -1/+1 pixel、
`z_top` 平移 -1/+1 pixel、背景跳过列数增加 2。正式主结果不由敏感性结果
替换。

每帧 QC 图显示 OMAG 定位、线性 `sv_raw` 显示、背景校正图、`P(z)`，并
叠加椭圆源区、矩形拖尾窗和双侧背景条带。六面板同时显示结构图、OMAG、
SV raw、校正图、`V/B_left/B_right/B/T` 和 `P`。显示对数只作用于绘图副本。

## 9. 冻结与追溯

每次运行复制原始配置与清单，记录二者 SHA-256、软件版本、运行完成时间、
有效/无效帧数。逐帧权重数组使每个积分可重新计算。完成 QC 的运行放入
`data/processed/<run_id>/`，原始扫描保持只读并由 Git LFS 管理。
所有清单预声明的单侧背景排除写入 `logs/manual_adjustments.csv`；没有调整时
仍保留带字段名的空表。

单帧输入或定位异常以 NA 和 `frame_processing_error` 进入逐帧表，批内其余
帧继续执行。配置冲突、清单结构错误和输出写入失败属于运行级错误并终止。
